WAF

O que é WAF

Um WAF (Web Application Firewall) é um tipo especial de firewall projetado para proteger aplicações web contra ataques que exploram vulnerabilidades em seu código. Ele analisa o tráfego HTTP e HTTPS entre o cliente (navegador) e o servidor da aplicação, bloqueando solicitações maliciosas antes que causem danos.

O que ele faz

Ele filtra e monitora requisições enviadas ao site. Usa regras de segurança (signatures, listas brancas e negras, políticas de comportamento). Detecta e bloqueia ataques como:

  • SQL Injection
  • Cross-Site Scripting (XSS)
  • Cross-Site Request Forgery (CSRF)
  • File Inclusion
  • Session Hijacking.

    • Tipos de WAF

    Baseado em Rede Instalado fisicamente ou virtualmente na infraestrutura de rede da organização — geralmente próximo ao servidor web. Ele atua no tráfego antes mesmo de chegar à aplicação, usando appliances dedicados ou equipamentos de rede (como roteadores e load balancers com suporte a WAF).
    Baseado em Host É instalado diretamente no servidor da aplicação web, geralmente como um software ou módulo integrado ao servidor (por exemplo, Apache, Nginx ou IIS). Ele analisa requisições e respostas dentro do próprio sistema operacional onde a aplicação roda.
    Baseado em Nuvem É instalado diretamente no servidor da aplicação web, geralmente como um software ou módulo integrado ao servidor (por exemplo, Apache, Nginx ou IIS). Ele analisa requisições e respostas dentro do próprio sistema operacional onde a aplicação roda.

    Como funciona

    O domínio do site (ex: www.exemplo.com) é configurado para passar primeiro pelos servidores do provedor WAF em nuvem. O provedor:

  • Analisa e filtra todo o tráfego HTTP/HTTPS.
  • Bloqueia requisições suspeitas (SQL Injection, XSS, DDoS, bots maliciosos).
  • Entrega apenas o tráfego limpo para o seu servidor.
  • O site continua funcionando normalmente, sem precisar alterar seu código.
