Visão Geral

O WAF (Web Application Firewall) atua como uma barreira inteligente entre o usuário da web e o servidor da aplicação.
Ele analisa, filtra e monitora todas as requisições HTTP/HTTPS, identificando padrões suspeitos antes que cheguem à aplicação. Em outras palavras:
👉 O WAF lê o que entra e sai do site, e decide o que é seguro e o que deve ser bloqueado.

Etapas de funcionamento

1. Inspeção de requisição

O WAF recebe a requisição do usuário antes dela chegar ao site. Ele examina cabeçalhos, parâmetros, cookies e corpo da mensagem. Exemplo: alguém envia um campo de formulário com código suspeito (script ou ' OR '1'='1).

2. Aplicação de Regras de Segurança

O WAF compara o conteúdo da requisição com um conjunto de regras pré-definidas. Essas regras identificam comportamentos típicos de ataques: SQL Injection Cross-Site Scripting (XSS) CSRF File Inclusion Exploração de vulnerabilidades conhecidas (CVE)

3. Bloqueio ou permissão

Se o WAF detectar algo suspeito, ele: Bloqueia a requisição, Envia alerta ao administrador, E registra o evento em logs. Caso contrário, a requisição é liberada normalmente para o servidor.

4. Monitoramento e Aprendizado

Alguns WAFs modernos utilizam Machine Learning (ML) para aprender com o tráfego real. Assim, eles ajustam as regras automaticamente, reduzindo falsos positivos e aumentando a precisão.

O que é Wafw00f

O Wafw00f é uma ferramenta de fingerprinting desenvolvida pela OWASP que serve para detectar se um site está protegido por um WAF e, se estiver, identificar qual tecnologia está sendo usada (como Cloudflare, ModSecurity, F5 BIG-IP, Akamai, entre outros).

Como funciona

O Wafw00f analisa respostas HTTP e códigos de cabeçalhos para identificar padrões característicos de cada WAF.
Ele envia requisições e interpreta detalhes como:

  • Cabeçalhos HTTP específicos (Server, Set-Cookie, Via, X-*)
  • Códigos de resposta e mensagens de erro
  • Comportamento do servidor ao detectar ataques simulados

    • Exemplo:
    Se o Wafw00f envia uma requisição suspeita e o servidor responde com um erro típico do ModSecurity, ele conclui:

    “ModSecurity WAF detectado.”

    🧰

    Onde usar

    Em auditorias e testes autorizados para mapear defesa de aplicações web; também útil para ajustar scanners e evitar falsos positivos.

    ⚖️

    Ética

    É importante lembrar:

    O Wafw00f não invade nem explora falhas. Ele apenas detecta e informa a presença de um WAF.

    Portanto, seu uso deve ser ético e autorizado — apenas em sites próprios ou com permissão, dentro de testes controlados.

    Instalação e uso (no Kali Linux)

    O Kali Linux já vem com o Wafw00f instalado por padrão.
    Mas, se não estiver, é fácil instalar:

    Linha de comando Kali-Linux

    sudo apt install wafw00f -y

    Exemplo de uso:

    Linha de comando Kali-Linux

    wafw00f https://www.exemplo.com

    Saída típica:

    Linha de comando Kali-Linux

    [*] Checking https://www.exemplo.com
    [+] The site https://www.exemplo.comCloudflare (Cloudflare Inc.)

    Prinipais usos

    O Wafw00f é útil em duas situações principais:
    1. Auditorias de segurança — identificar se um site está protegido por WAF e qual tipo.
    2.Testes de penetração (ethical hacking) — ajustar ferramentas ofensivas (como SQLMap ou Burp Suite) para evitar falsos positivos causados pelo WAF.
