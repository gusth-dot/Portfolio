Projeto Site Fã Marvel

Este projeto consiste no desenvolvimento de um site acadêmico com temática voltada ao universo Marvel, com o objetivo de aprimorar conhecimentos em programação, gerenciamento de conteúdo e organização de interfaces digitais.
A proposta envolve a criação de uma plataforma interativa que reúne informações sobre personagens, filmes e elementos marcantes do universo Marvel, buscando proporcionar uma experiência visual atrativa e intuitiva para o usuário. Durante o desenvolvimento, estão sendo aplicados conceitos de HTML, CSS e JavaScript, com foco em responsividade, usabilidade e design moderno.
Além disso, o projeto também contribui para o desenvolvimento de habilidades relacionadas à estruturação de páginas web, organização de componentes e implementação de funcionalidades dinâmicas, como navegação interativa e animações.
Atualmente, o site ainda se encontra em fase de desenvolvimento, com melhorias contínuas sendo realizadas tanto na parte visual quanto funcional, visando evoluir o projeto para um nível mais completo e profissional.
